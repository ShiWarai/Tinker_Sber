# Прошивка платы управления роботом

Прошивка для контроллера на **STM32F405** (проект Keil: OmniBotHub_Core). Плата обеспечивает обмен данными с одноплатным компьютером и управление приводами.

## Назначение

- **CAN** — обмен с моторами **DM8006** и **DM6006** (протокол MIT): приём обратной связи (положение, скорость, момент), отправка команд управления. Поддержка **SCS-сервоприводов** (SMS/STS) по отдельному интерфейсу.
- **IMU по SPI** — чтение инерциального датчика и передача данных на одноплатник.
- **Память (Flash)** — хранение и загрузка параметров, конфигурации.
- **Светодиоды** — индикация режимов и состояния.
- **Beep (зуммер)** — звуковая индикация (калибровка, ошибки, статус).

Плата выступает мостом: данные с CAN и IMU уходят на одноплатник, с одноплатника приходят команды на CAN для моторов DM8006/DM6006 (и при необходимости — управление SCS).

## Сборка

- Среда: **Keil µVision** (ARM Compiler 5).
- Открыть `F407_FC.uvprojx`, собрать проект. Результат в `build/`.

## Структура (основное)

- `drivers/` — CAN, SPI (IMU), Flash, USART, LED, beep, питание и др.
- `SCSs/` — драйверы SCS-сервоприводов (SMS_STS, SCSerial и т.д.).
- `balance_controller/`, `quadruped_src/` — остатки логики походки/баланса; для режима «только мост» не используются.

В текущей конфигурации прошивка ориентирована на передачу данных CAN/IMU и управление моторами DM8006/DM6006 и SCS при сохранении работы с памятью, светодиодами и периферией.
